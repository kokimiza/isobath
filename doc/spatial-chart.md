# 3次元海図：運用モデルと表示の契約

2026-09-24。自動運用は `schema_version=4`、座標系 `latent3-v1` を使用する。
この追補は、[統計仕様 v0.3](statistics.md) の16因子から2軸を射影するサービス表示を置き換える。
旧研究CLI・schema 3・過去の2次元履歴は互換性のため残す。

## 推定する量

個人の潜在位置は **f ∈ R³**。順序プロビット測定モデル、MFM混合事前、
Gibbs + split-merge、cut推論／学習者の同時事後は既存の方式を使う。
各保存ドローで混合分布の平均を0、軸ごとの分散を1に標準化する。
画面の位置はその事後平均 `(X,Y,Z)`、表示行列は `P=I₃`。
Zは回答から推定する第3因子であり、2次元座標に人工的な深さを足した値ではない。

16の質問領域を3つの性格カテゴリにまとめることはしない。D01・D04・D07の
正方向の共通項目の最小IDを、順にX・Y・Zの向きの基準とする。
その3行の負荷行列には正の対角と上三角の厳密なゼロ制約を置く。
基準領域の主負荷事前は従来の平均 `0.6 × keyed`、標準偏差0.3
（基準項目の対角は0.2、正値に切断）、交差負荷は平均0・標準偏差0.1。
残りの領域は3軸すべてについて平均0・標準偏差0.3の自由負荷とする。

これは軸の向きと事前分布を定める**モデル上の規約**であり、データだけから
人格が本質的に3次元であると同定したという主張ではない。混合共分散も推定するため、
回転・せん断・尺度に関する識別は制約と事前にも依存する。別モデル版の座標差は
個人の変化と同一視せず、版をまたぐ軌跡は結ばない。

## 海域境界と本人の所属確率

代表分割へ対応付けた海域 `r` の事後予測確率を、同じ標準化3次元空間で計算する。

```text
q_r(x) = Eθ[ Σ_{c: mapθ(c)=r} wθc N₃(x; mθc, Σθc) ]
         / Eθ[ Σ_c wθc N₃(x; mθc, Σθc) ]
```

全保存ドローを等重みで使う。分母には未観測成分・対応失敗成分も含める。
海域の「内側」は `q_r(x) ≥ 0.5`、境界は `q_r(x)=0.5`。
どの海域も50%に達しない位置は移行帯／未分類とする。同率の境界を除き海域の内側は重ならない。
`sea_at_mean` は本人の事後平均でこの式を直接評価した結果であり、粗い表示格子で判定しない。

一方、既存の `regions[].p` は `P(r | 本人の回答)`。
不確実な位置とモデルドローを積分した所属確率なので、平均位置での `q_r` とは異なる。
UIでは「現在地の海域」と「回答からの所属確率」を区別する。
海域は、既存の複数群判定を満たすCHARTEDモデルでのみ提供する。
PRIORでは位置を表示するが、架空の海域を生成しない。

## 個人の不確実性と描画

- 3次元事後ドローをKDEで近似し、格子の確率質量を高い順に積み上げた
  約95%のHPD信用領域を保存する。表示には約50%の内側も重ねる。
- Scott型の3次元帯域係数 `n_eff^(-1/7)` を用いる。計算量を抑えるため
  KDE評価に使うドローは保存順から等間隔で最大2,048点。
  分布の尾・多峰性・強い相関によって近似誤差が生じうる。
- 校正済み成果物は、独立チェインで構築／評価を分け、20³→28³→40³で
  体積5%以内・質量1%以内の安定性と保持チェインの被覆／MCSEを確認する。
  不合格なら公開しない。PRIORの軽量推論にはこの合格を主張しない。
- 各軸の2.5–97.5百分位も返す。これは周辺信用区間であり、3軸の同時95%領域ではない。
- 公開海域は `[-3,3]³` の21³点で計算し、marching tetrahedraで等値面を補間する。
  表示範囲に接する海域は切断される。個人HPDは自身の計算範囲で描く。
- D3の[drag](https://d3js.org/d3-drag)、[zoom](https://d3js.org/d3-zoom)、
  [linear scale](https://d3js.org/d3-scale/linear)を使い、Canvasへ回転投影する。
  D3の2次元contourを3次元推定器として扱わない。カメラ操作は推定値を変えない。
- 公開観測密度は3次元セルごとに従来のk抑制を適用する。個々人の座標や事後ドローは
  公開レスポンスへ含めない。本人の信用領域は認証済みの本人用レスポンスだけに含める。
- 従来の `confidence` は `1/(1+平均事後分散)` で、正答率ではない。
  UIでは「推定の集中度」と表記する。座標・信用領域・所属確率を別々に表示する。

## 本番への反映

フロントエンド／APIを通常の手順で反映し、新しいコードの GitHub Actions `nightly` を実行する。
既存の `NIGHTLY_DATABASE_URL` と適用済みの `20260924000000_scheduled_models.sql` だけで動く。
今回の変更には追加SQLマイグレーション、DB権限、Secret、seedの変更は不要。

成功済み2次元バッチでも同じ締め時刻に1回だけ3次元への移行を許す。
旧bundleのパラメータを流用せず、新しい `prior3-v1-*` を作成して全対象者を再配置する。
成功した3次元バッチの再実行はスキップ。過去日の履歴は残るが、同じ締め時刻の旧位置は更新される。
初期化から14日ごとの再推定・診断不合格時の据置きは従来どおり。

## 検証範囲

実装テストは、3因子サンプラーの制約、保存形式、独立正規標本での体積被覆、
Zだけで変わる海域判定と描画格子の一致、3次元セルのk抑制、旧版からの切替、
日次処理の再実行、PC／スマートフォンでの操作を対象とする。
新モデルのSBC・回復実験の1,000反復、実データでの因子数・予測性能・境界安定性は未検証。
既存の16因子研究CLIの検証結果を、この3因子モデルの妥当性の根拠として流用しない。
MFMの数理は[Miller & Harrison](https://arxiv.org/abs/1502.06241)に基づくが、
同論文は本サービスの3因子仮説や境界の実証的妥当性を保証するものではない。
