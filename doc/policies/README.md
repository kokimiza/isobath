## 同意の設計（レビュー #4, #6, #11 への対応）

| 同意 | 必須/任意 | 記録 |
|---|---|---|
| 利用規約 | 必須 | `app.consent_events`（grant） |
| プライバシーポリシー | 必須 | 同上 |
| 18歳以上であること | 必須 | 画面上の確認のみ（利用規約第3条） |
| 非診断であることの理解 | 必須 | 画面上の確認のみ |
| 研究への参加 | **任意** | `app.consent_events`（grant / withdraw） |

- 研究に参加しない利用者も、測深と結果表示を利用できる。位置は参加者のデータから作った海図に射影するだけなので、サービスとして成立する。
- 研究参加は設定画面から撤回・再参加できる（`PUT /v1/me/research`）。撤回した利用者のデータは `analysis.research_participants` による絞り込みで `analysis.responses` から除外される。
- 同意履歴は追記のみ（UPDATE / DELETE の権限なし）。アカウント削除時は `user_id` を null にし、仮名IDと履歴だけを証明用に残す。
- 文書の版を上げたら `app/isobath/config.py` の `CONSENT_VERSIONS` も上げ、再同意を求める。
