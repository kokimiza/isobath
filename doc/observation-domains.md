# ISOBATH 観測領域定義
## Item Set Draft v0.1

---

# 1. 位置付け

観測領域は**因子ではない**。

質問を漏れなく、重複なく作るための**設計上の区分**である。

- 領域名を既存尺度の因子へ対応付けない（「対人接近性 = Extraversion」とは定義しない）。
- 実データ上、複数領域が一つの潜在因子にまとまる、あるいは一つの領域が複数因子へ分かれる場合、その結果を受け入れる。
- 領域区分はPilot後の分析で使用しない。分析は項目単位で行う。

### アンカー配分を均等にする理由

特定領域にアンカーを厚く配分すると、共通潜在空間がその領域に寄った形で構成される。
既存理論に近い領域を厚くすることは、既存理論を設計に持ち込むことになる。

したがって全領域2問（項目数の少ないD11・D13は1問）の均等配分とする。

# 3. 領域定義

各領域について、

- **定義**
- **含むもの**
- **含まないもの**（→ 扱う領域）
- **質問作成方針**

を定める。「含まないもの」は隣接領域との境界であり、似た質問の量産を防ぐためのものである。

---

## D01 対人接近性

**定義**
他者との交流・接触・関与をどの程度求め、どの程度の距離を快適と感じるか。

**含むもの**
- 交流の頻度に対する欲求
- 初対面の相手への接近
- 一人で過ごす時間の好み
- 関係の広さ（多くの人）と深さ（少数と密に）
- 交流後に活力が増すか、消耗するか

**含まないもの**
- 交流中の協力・対立の仕方 → D02
- 多数派への合わせ方 → D14
- 交流に伴う不安・緊張の強さ → D07

**質問作成方針**
- 「人が好き／嫌い」ではなく、具体的な場面での選択・行動を聞く。
- 量（頻度）と質（深さ）を別項目にする。
- 一人を好むことを否定的に描かない。

---

## D02 協調・対立傾向

**定義**
利害や意見が食い違う場面で、協力・譲歩・主張・対立にどう向き合うか。

**含むもの**
- 譲歩・妥協
- 自己主張
- 対立の回避・直面
- 相手の立場の考慮
- 不満を表明するか、飲み込むか

**含まないもの**
- 勝敗・比較そのものへの動機 → D16
- 多数派への合わせ方 → D14
- 怒り等の感情の起きやすさ → D07

**質問作成方針**
- 社会的望ましさの影響が強い領域。「協力的＝良い」と読める表現を避ける。
- 主張と協調を一つの項目の両極に置かず、別項目で聞く。
- 場面（職場・友人・家族等）を一つに偏らせない。

---

## D03 規範・秩序志向

**定義**
ルール、慣習、秩序、予測可能な手順をどの程度重視するか。

**含むもの**
- ルールの遵守
- 慣習・しきたりの尊重
- 整理整頓・環境の秩序
- 決まった手順どおりに進めること
- 例外や逸脱への抵抗感

**含まないもの**
- 自分で立てた計画の遂行 → D06
- 周囲の人に合わせること → D14
- 曖昧さそのものへの不快 → D05

**質問作成方針**
- 法令違反など望ましさが極端な内容ではなく、日常の軽微なルール・慣習で聞く。
- 規範の内容（政治・宗教・道徳的立場）には触れない。

---

## D04 探索・新奇性

**定義**
未知のもの、新しい経験、変化を**自ら求める**傾向。

**含むもの**
- 新しい場所・食べ物・趣味への関心
- 知的好奇心
- ルーティンへの飽き
- 変化を歓迎するか

**含まないもの**
- 未知の状況に置かれたときの耐性 → D05
- 金銭・身体・社会的損失を伴う選択 → D10
- 考えることそのものの好み → D12

**質問作成方針**
- 「接近する（求める）」側を聞く。D05との区別の鍵。
- 経済的余裕・居住地に依存する例（海外旅行、高額な体験等）を避ける。

---

## D05 不確実性耐性

**定義**
曖昧さ、情報不足、予測不能な状況に**置かれたとき**の反応。

**含むもの**
- 結論の出ない状態への耐性
- 先の読めない予定への反応
- 曖昧な指示への反応
- 確認・情報収集で不確実性を減らそうとする行動

**含まないもの**
- 未知を自ら求めるか → D04
- 損失可能性の評価 → D10
- ルールの重視 → D03

**質問作成方針**
- 本人が選んだのではなく「その状況に置かれた」形で聞く。
- 不安症状の有無ではなく、日常的な反応の傾向を聞く。

---

## D06 計画・自己統制

**定義**
目標に向けて計画し、持続し、衝動を抑え、遂行を管理する傾向。

**含むもの**
- 事前の計画
- 締切・進行の管理
- 継続・途中放棄
- 誘惑・衝動の抑制

**含まないもの**
- 外部ルールへの従属 → D03
- 即時報酬と将来報酬の評価 → D11
- 判断の速さ・迷い → D13

**質問作成方針**
- 「できる／できない」（能力）ではなく「普段どうしているか」（傾向）を聞く。
- 仕事・学業に場面を限定しない。

---

## D07 感情反応性

**定義**
出来事によって感情がどの程度、どの速さで動きやすいか。正負両方の感情を対象とする。

**含むもの**
- 不安・苛立ち・落ち込みの起きやすさ
- 喜び・感動・高揚の起きやすさ
- 感情の強さ

**含まないもの**
- 感情が動いた後に平常へ戻る過程 → D08
- 自己評価・自信の揺れ → D09

**質問作成方針**
- ネガティブ感情に偏らせない。正の感情の項目を含める。
- 臨床的症状（不眠、希死念慮、パニック等）を聞かない。ISOBATHは非医療・非診断である（concept §59）。

---

## D08 感情回復性

**定義**
ストレス、失敗、不快な出来事の後に平常状態へ戻る傾向。

**含むもの**
- 引きずる時間
- 気持ちの切り替え
- 反芻（繰り返し思い返す）
- 回復のために取る行動

**含まないもの**
- 感情の起きやすさ・強さ → D07

**質問作成方針**
- 「〜した後」という時間軸で書き、感情が動いた後の過程に限定する。
- D07と同じ出来事の例を使い回さない。

---

## D09 自己評価安定性

**定義**
自己評価や自信が、状況や他者の評価によってどの程度変動するか。

**含むもの**
- 褒められた／批判された後の自己評価の変化
- 成功・失敗による自信の変動
- 他者と比べたときの自己評価の揺れ

**含まないもの**
- 自己評価の水準（高い／低い）そのもの → 本領域では扱わない
- 他者と比較したいという動機 → D16

**質問作成方針**
- 水準と変動を混ぜない。「自分に自信がある」ではなく「〜によって自信が変わる」の形で聞く。

---

## D10 リスク選好

**定義**
損失の可能性を伴う選択に対する態度。

**含むもの**
- 金銭的リスク
- 身体的リスク
- 社会的リスク（評判・人間関係）
- 確実な小さい利益と、不確実な大きい利益の選択

**含まないもの**
- 新しさそのものへの関心 → D04
- 報酬を受け取る時期 → D11

**質問作成方針**
- リスクの種類（金銭／健康／社会／娯楽）を分散させる。
- 所得に依存する金額表現を避け、相対的な表現を使う。
- 違法行為を含めない。

---

## D11 時間選好

**定義**
即時の報酬と将来の報酬をどう評価するか。

**含むもの**
- 今すぐ得るか、待って多く得るか
- 将来のために現在を我慢するか
- 貯蓄・先行投資に対する態度

**含まないもの**
- 計画の実行・進行管理 → D06
- 将来報酬が得られるかどうかの不確実性 → D10

**質問作成方針**
- シナリオ型の項目では、将来報酬が確実に得られる前提を明示し、D10と分離する。
- 金額は相対的な表現を使う。

---

## D12 認知熟慮性

**定義**
判断において直感と熟考のどちらを使いやすいか。

**含むもの**
- 考え抜くことを楽しむか
- 第一印象・直感への信頼
- 判断前に集める情報の量
- 根拠を求める傾向

**含まないもの**
- 決断の速さ・迷い・後悔 → D13
- 新しい知識への好奇心 → D04
- 正答できるかどうか（認知能力） → 測定しない

**質問作成方針**
- 正誤のある能力テスト形式（CRT型の問題）にしない。好みと習慣を聞く。

---

## D13 意思決定確信

**定義**
判断を下す速さ、迷い、決定後の確信・後悔。

**含むもの**
- 決めるまでにかかる時間
- 選択肢の間での迷い
- 決定後の確信・後悔・見直し

**含まないもの**
- 判断の過程が直感か熟考か → D12
- 事前に計画を立てること → D06

**質問作成方針**
- 決定前（迷い・速さ）と決定後（確信・後悔）を別項目にする。

---

## D14 集団同調性

**定義**
周囲の判断、多数派、場の空気から受ける影響の大きさ。

**含むもの**
- 多数派の意見に合わせる
- 場の空気に応じて意見を変える
- 流行・周囲の選択の影響

**含まないもの**
- 明文化されたルール・慣習の重視 → D03
- 交流したいという欲求 → D01

**質問作成方針**
- D15の逆転項目として書かない。D14とD15が一つの次元に収束するかどうかは実データで判断する。
- 「空気を読む」は日本語の文脈で評価的な意味を帯びやすい。中立的な行動記述にする。

---

## D15 自律性

**定義**
他者や集団から独立して判断・行動する傾向。

**含むもの**
- 一人で決める
- 他者の承認を得ずに行動する
- 自分の基準で評価する

**含まないもの**
- 対立への向き合い方 → D02
- 周囲からの影響の受けやすさ → D14

**質問作成方針**
- 独立を「反抗」や「孤立」と混同しない。

---

## D16 競争・達成志向

**定義**
比較、勝敗、成果、成長に対する動機。

**含むもの**
- 勝ちたいという気持ち
- 他者との比較
- 目標を達成したいという欲求
- 自己成長への動機

**含まないもの**
- 対人対立への対処 → D02
- 遂行の管理 → D06
- 比較による自己評価の揺れ → D09

**質問作成方針**
- 他者基準（競争）と自己基準（成長）を別項目にする。

# 5. 共通の項目作成規則

### 回答形式
- 全項目を5件法（1〜5）で統一する（DB制約 `CHECK answer BETWEEN 1 AND 5`）。
- シナリオ型の項目も5件法で回答させる。回答形式の違いによる方法因子を避けるため。

### 文面
- 1項目で1つの内容だけを聞く（二重質問の禁止）。
- 二重否定を使わない。
- 時間枠は「普段の自分」とする。
- 領域名や専門用語を項目文に出さない。

### バイアス対策
- 各領域の1/3〜1/2を逆転項目にする（黙従傾向への対策）。
- 社会的望ましさが一方に大きく偏る表現を避ける。

### 対象外
- 特定の文化・職業・年齢・性別・所得・家族構成・居住地に依存する内容
- 臨床症状、能力の測定、政治・宗教的立場、違法行為

### 出題
- 領域順に並べない。出題順はランダム化する（concept §3.3.1）。

# 6. アンカー選定基準

アンカーは「代表質問」ではなく、**全回答者を同じ潜在空間へ接続するための共通測点**である。

以下を優先する。

- 回答分布が極端になりにくい（天井効果・床効果が出にくい）
- 曖昧さがない
- 特定の文化・職業・年齢に依存しにくい
- 一つの行動・態度だけを聞いている
- 他のアンカーと内容が重複しない

アンカーはPilot結果を見て入れ替える。入れ替えはItem Set Versionの改訂として扱い、linking itemsを残す（concept §3.3）。

# 7. ブロック構成

ブロックは領域単位で作らず、**各ブロックに全領域の項目を層化して配置する**。

    Block A = D01×2 + D02×2 + ... + D16×1
    Block B = D01×2 + D02×2 + ... + D16×1
    ...

理由：
- 1ブロック＝1領域にすると、領域内の項目ペアの共回答数は増えるが、領域をまたぐペアの共回答数が大きく下がる。
- これは「領域内の相関が重要である」という仮定を、測定精度の配分として設計に埋め込むことになる。
- 領域は因子ではないため、特定の項目ペアを設計上優遇しない。
- 全回答者がすべての領域に触れる。

試算（アンカー以外200問 = 20問 × 10ブロック、1人3ブロック = 60問）：

| 項目ペア | 共回答率 | N=1,000時 |
|---|---|---|
| アンカー × 全項目 | ≥ 3/10 | ≥ 300 |
| 同一ブロック内 | 3/10 | 約300 |
| 異なるブロック間 | 1/15 | 約67 |

# 8. 品質確認項目

人格項目とは別枠で管理し、人格モデルの分析変数にしない。

    Personality items
            ↓
    人格モデル

    Quality items
            ↓
    回答信頼度

種類：
- 注意確認項目（指定の選択肢を選ばせる）
- ほぼ同じ意味の再質問（回答の一貫性）
- 明らかに矛盾する項目ペア
- 回答時間（項目ではなくメタデータとして記録）

1人あたり5〜10問とする。

# 9. 次の工程

1. 本定義のレビュー・確定
2. 領域ごとに候補項目を作成する（領域の定義・含むもの・方針に従う）
3. 項目レビュー：二重質問、望ましさの偏り、領域の境界、項目間の重複
4. アンカー30問の選定
5. ブロック割当表の作成
6. Pilot（Phase 1）開始

各項目に持たせるメタデータ：

    item_id
    domain         (D01〜D16、設計区分であり分析には使わない)
    facet          (含むものの該当項目)
    keyed          (+ / -)
    anchor         (true / false)
    item_type      (personality / quality)
    text_ja
    note
