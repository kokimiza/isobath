# 人格海図 ISOBATH
## 統計仕様書 v0.3（ベイズ順序尺度・因子混合モデル）

> **Python実装とテストを追加した仕様である。** `app/pipeline` が推定・検証・成果物生成を、`app/isobath/inference` と `isobath.nightly` が個人位置の計算を担う。実行手順と仕様対テスト表は [statistics-implementation.md](statistics-implementation.md) を参照。実装テストの合格は、§9の1,000反復による本評価の合格や、実データ上の妥当性を意味しない。`CURRENT` は自動変更しない。

**この方式を採る理由**：回答者の人数でモデルや処理を切り替えない。1人でも100万人でも、**生成モデル・推定対象・意思決定規則**は同じものを使う。人数が変われば事後分布は変わる。広さだけでなく、中心・形・峰の数・代表分割も変わる。変えないのは「何を仮定し、何を推定し、どう決めるか」であって、「答えが同じ」という意味ではない。群の数を解釈したい量として扱うため、成分数そのものに事前分布を置く有限混合（MFM: Miller & Harrison 2018）を使う。**この文書が支える研究の問いと仮説は §0 に置く。** 何をもって結論とするかは §0.3 の手続きで決める。

# 0. 研究の問いと仮説

**問い：人の回答傾向は、データが増えるといくつのまとまりとして現れ、その数は安定するのか。**

目的は「固定タイプを作ること」ではない。**まとまりが存在するのか、その数・特徴・境界が、観測の蓄積に対してどこまで再現するのかを明らかにすること**である。したがって「少数の群に落ち着く」「細分化が続く」「明確な群がない」のいずれも研究結果として認める。群が見つからないことも成果である。

## 0.1 仮説

| 仮説 | 内容 | 検証するもの |
|---|---|---|
| 主仮説：群構造の安定化 | 回答者が増えるにつれ、再現性のある少数の回答傾向が現れ、群数と特徴が一定範囲に安定する | 標本サイズ別の `P(T_n)`、独立標本での群プロフィールの再現性 |
| 対立仮説：連続的な個人差 | 回答傾向は連続的に広がり、安定した境界を持つ群には分かれない | 柔軟な連続分布モデルとの予測性能比較、分割の不安定さ |
| 対立仮説：階層的な構造 | 大きな傾向は安定するが、その内部に細かな傾向が現れる | 大分類と小分類それぞれの再現性 |
| 副仮説：希少な傾向の発見 | 少人数では見えなかった少数群が、標本の増加で再現可能になる | 別の標本でも同じ傾向が現れるか、外れ値だけで構成されていないか |

比較対象は、同じ測定モデル・測定事前（§2.1、§3）のもとで、(A) `f_i ~ N_16(m,Σ)`、(B) `f_i ~ t_ν(m,Σ)` とする。両者の `(m,Σ)` は §3 と同じNIW事前、Bは `ν=2+u, u~Exponential(rate=0.1)` とし、`Σ` はt分布の尺度行列（共分散は `νΣ/(ν-2)`）とする。歪みのある連続分布への頑健性は §9.2 の誤指定実験で別に測る。

## 0.2 「増えるもの」を区別する

| 増えるもの | 主に分かること |
|---|---|
| 回答者数 | 母集団内の多様性、希少な傾向 |
| 1人あたりの回答項目数 | 個人の位置の推定精度 |
| 同じ人の回答回数 | 個人内の変動、測定の安定性 |
| 観測期間 | 母集団や個人の時間変化 |

同じ人が毎日回答しても、独立した回答者が増えたことにはならない。**日々の海図更新の履歴は、主仮説の検証には使えない**（人数の増加と、時代・利用者層の変化が混ざる）。

## 0.3 標本サイズ実験（主仮説の検証手続き）

日次バッチとは別に、`pipeline` のサブコマンドとして実行する。

1. **回答者単位**で学習プール・予測評価標本・構造再現標本を分離する。同じ人の回答を跨がせない。同じ期間・同じ項目版で、学習プールから入れ子標本 `n=100,300,1,000,3,000,…` を作る。20反復は予備実験のみ、本評価は100反復とし、重複抽出を独立な母集団標本とは数えない。
2. 各標本で `P(T_n)`、`P(K)`、`T̂`、credible ball、プロフィールを記録する。プロフィールは、各代表海域の構成員の16次元事後平均を平均した値とし、共通の参照尺度で比較する。独立標本間はプロフィールの距離最小のHungarian対応を使い、未対応も報告する。
3. **固定モデルの予測検証**では再学習せず、各ホールドアウト回答者について `p(y_i|Y_train)=∫[∫p(y_i|f,θ)p(f|θ)df]p(θ|Y_train)dθ` を計算する。本人の因子得点を積分し、未回答項目は尤度から除く。各モデルに同じ回答・欠測パターンを使い、回答者あたりの対数予測密度差（nat）と回答者単位のbootstrap 95%区間を報告する。数値積分のMCSEも併記する。
4. **構造再現**では、互いに重ならない同人数の標本にモデルを独立に再推定する。固定モデルで所属を再予測するだけでは、構造再現の証拠にしない。独立標本が確保できなければ、この検証は未達とする。
5. **安定化の事前登録基準**：最大側の連続する3標本サイズで、隣接サイズ間の群数分布の全変動距離 `TV(P(T_n),P(T_n'))≤0.10`、対応プロフィールの最大RMS距離（16領域の参照尺度）`≤0.20`、未対応海域の構成員比率 `≤0.05`、回答者あたり対数予測密度の変化の絶対値 `≤0.05 nat` をすべて満たす。独立標本の再推定にも同じ構造基準を適用する。各上限指標の片側95%信頼上限が基準内にあることを要求する。反復をまたぐ区間は元の回答者を単位に標本抽出・再推定を含めてbootstrapし、重複する反復を独立と仮定しない。
6. 主仮説を支持するには5に加え、両連続モデルに対する対数予測密度差の95%区間下限が0を超え、§9.3で複数海域表示となる必要がある。満たさない場合は「安定化未確認」とし、直ちに連続性や階層性の証明とはしない。これらは研究上の操作的基準であり、予備実験後・本評価前に固定し、変更は新プロトコルとして記録する。
7. 階層性は、親海域の選択・所属判定・再クラスタリングの**全手続き**を、§0.1の連続帰無モデルからのシミュレーションにも適用する。内部分割のVI改善量（1群分割の事後期待VI損失から最適候補の損失を引く）を統計量とし、親海域間の最大値による帰無95%点で多重選択を調整する。独立標本でも親海域の選択から再推定し、5の構造基準を満たすか確認する。選択による切断だけで生じる分割を階層性と呼ばない。
8. 希少群の品質・時期・外れ値への依存、抽出シード、標本定義、項目版、参照尺度、コミット、区間の計算法を記録する。希少群の再現性も独立標本で確認する。

## 0.4 前提にしないこと

**「人数が増えれば真の人格タイプ数に収束する」とは前提にしない。** 混合モデルでは、分布の形がモデルの仮定とずれているだけでも、データの増加に伴って成分数が増えうる（Cai, Campbell & Broderick 2021）。ディリクレ過程・Pitman-Yor 混合の成分数が一致性を持たないことも知られている（Miller & Harrison 2014）。MFM は成分数を推定対象として扱えるが、**モデルが正しいという条件のもとでの話である。**

したがって、`T_n` の安定性は**経験的に測る対象**であり、モデルが保証する性質ではない。§9.2 の誤指定データでの検証（歪み・裾・局所依存・不注意回答）と、§9.4 の事後予測検査が、この解釈の前提条件になる。

## 0.5 個人内変動（縦断）

現仕様は**項目ごとの最新回答だけ**を使う（§1）。この設計では、同じ人の過去からの変化を分析できない。

- 繰り返し回答を研究に使うなら、個人内変動を扱う縦断モデル（位置の時間変化と測定誤差を分離するモデル）が必要である。**LATER とする。**
- 現行の Drift 判定（requirements ST-DRF）は、位置スナップショットの系列に対する別手続きであり、モデル内で個人内変動を推定していない。縦断モデルを入れるまで、「人格が変化した」という主張はしない（ST-DRF-03、FR-JNY-04）。
- 継続測深の回答は、当面は「その人の最新の位置の推定精度を上げるもの」として扱う。

# 1. 記号と対象データ

| 記号 | 意味 |
|---|---|
| `i = 1..N` | 観測者（利用者） |
| `j = 1..J` | 人格項目。`kind = 'personality'` のみ。品質確認（`quality`）と比較尺度（`comparison`）は除外する |
| `O_i` | 観測者 `i` が回答した項目の集合（Planned Missing により `|O_i| << J`） |
| `y_ij ∈ {1,..,5}` | 5件法の回答。項目ごとに最新の回答を1つ使う（§10 の注意） |
| `d(j) ∈ {1..16}` | 項目 `j` が属する観測領域（`app/items/items-*.csv` の `domain`） |
| `s_j ∈ {+1,-1}` | 項目 `j` の記述方向（同CSVの `keyed`） |
| `f_i ∈ R^16` | 観測者 `i` の潜在位置 |
| `K` | 母集団モデルの混合成分数 |
| `T_N` | この標本で実際に埋まった（空でない）成分の数。`T_N ≤ K` |
| `T̂` | 代表分割（§6.1）の海域数 |
| `z_i` | 観測者 `i` の所属成分 |

- 逆方向項目の回答値は前処理で反転しない。方向は負荷の事前分布で扱う（§3）。
- Planned Missing の未回答は、尤度に現れないだけで扱える。補完しない。前提の確認は §10。
- モデルの推定に使うのは、研究参加の同意が有効な観測者のデータのみ。**したがって推定結果が直接記述する対象は、まず「同意した回答者の集団」である**（§10）。同意していない観測者は推定に寄与せず、確定した成果物を使って自分の位置だけを得る。

# 2. モデル

## 2.1 測定モデル（順序プロビット）

    y*_ij = λ_j' f_i + ε_ij,        ε_ij ~ N(0, 1)
    y_ij = c   ⟺   τ_{j,c-1} < y*_ij ≤ τ_{j,c}
    τ_{j,0} = -∞ < τ_{j,1} < τ_{j,2} < τ_{j,3} < τ_{j,4} < τ_{j,5} = +∞

- 残差分散を1に固定する。項目の切片と分散は閾値 `τ_j` に吸収されるため、別に持たない。現行成果物の `mu`・`scale`・`psi` は不要になり、`tau` が代わる。
- **天井・床効果は `τ_j` だけからは読めない。** 端カテゴリの選択率は因子の分布にも依存する。事後予測での端カテゴリ出現率で評価する（§9.4）。

## 2.2 構造モデル（MFM）

    f_i | z_i = k  ~  N_16(m_k, Σ_k)
    z_i | w, K     ~  Categorical(w)
    (w_1..w_K) | K ~  Dirichlet(γ, .., γ)
    K              ~  p_K(·)   on {1, 2, 3, ...}

`w` と `K` を積分消去すると、分割（どの観測者が同じ成分に属するか）の分布として書ける（Miller & Harrison 2018）。分割が `t` 個のブロック `{c}` を作るとき

    p(partition) = V_n(t) · Π_c γ^{(|c|)}
    V_n(t) = Σ_{k≥1} [ k_{(t)} / (γk)^{(n)} ] · p_K(k)

`x^{(m)}` は上昇階乗、`x_{(m)}` は下降階乗である。**この分割分布を実装対象とする。** 有限打ち切りは数値近似であり、上限 `L` は探索可能な群数も制限する。事前の裾確率だけで精度を保証しない。

- 級数項 `a_k(n,t)=k_{(t)}p_K(k)/(γk)^{(n)}` を対数で計算し、log-sum-expで加算する。`k<t` は0。要求された `t` と次の提案 `t+1` に対して必要な範囲まで必ず上限を拡張し、未計算を確率0と扱わない。
- 正の残余和 `R_L` の上界を項の比から求める。§3のPoisson事前（平均パラメータ `λ_K=1`）なら、`k≥max(t,1)` で `a_{k+1}/a_k ≤ λ_K(k+1)/[k(k+1-t)]`。右辺は以後減少するので、`q=λ_K(L+2)/[(L+1)(L+2-t)]<1` なら `R_L≤a_{L+1}/(1-q)`。感度分析で事前を替えたときも有効な残余上界を導出する。
- 要求された各 `(n,t)` について相対残余上界 `R_L/Σ_{k≤L}a_k≤1e-10` を満たし、分子・分母の上下界から `V_n(t+1)/V_n(t)` の相対誤差上界も `≤1e-8` とする。`t=0`、`n=1` も扱う。§4.2.1のK復元にも同じ正規化誤差管理を使う。
- 上限を最低2倍、許容誤差を10分の1にした独立再実行で、`P(T_N)`・`P(K)` のTV距離がそれぞれ `≤0.01`、新規利用者の未観測成分確率の差が `≤0.005` で、表示判定が変わらないことを確認する。差のMCSEが各許容差の3分の1以下になるまで計算する。失敗時は上限・チェイン長を増やし、解消まで成果物を確定しない。上限、残余上界、比の誤差、再実行差を保存する。

- **DPM ではなく MFM を使う理由**：DPM の成分数は標本サイズとともに増え続け、「群がいくつあるか」の推定量にならない。
- **疎な有限混合（固定 `K_max` と `Dirichlet(γ/K_max)`）は使わない。** `γ=1`・`K-1~Poisson(1)` のMFMでは、回答を見る前に2人が同じ群に属する確率が `Σ_k e^{-1}/(k-1)! · 2/(k+1) ≈ 0.736`、`K_max=15`・`Dirichlet(1/15)` では `(1/15+1)/2 ≈ 0.533` である。黎明期の海図を左右する差であり、別のモデルになる。計算の都合でそちらを選ぶなら、仕様全体をそのモデルで書き直す。今はしない。

# 3. 事前分布

少人数でも成立させる情報は、質問票の設計（16領域の割当と記述方向）から取る。**1人の回答から軸を発見することはできない。軸は仮説として与える。**

| 対象 | 事前分布 | 意図と注意 |
|---|---|---|
| 符号アンカー項目の主負荷（因子ごとに1項目） | `s_j · λ_{j,d(j)} ~ N_+(0.6, 0.2²)`（正に切断） | 因子の符号を固定する規約（§5）。因子ごとに1項目だけ切断する |
| その他の主負荷 `λ_{j,d(j)}` | `s_j · λ_{j,d(j)} ~ N(0.6, 0.3²)`（切断しない） | 設計上の仮説を弱く入れる。**切断しないので、設計と逆向きの負荷も推定できる**（v0.1 からの変更） |
| 交差負荷 `λ_{j,k}, k ≠ d(j)` | `N(0, 0.1²)` | 1つの項目が他領域も測ってしまう度合い。**因子間の相関とは別の概念**であり、因子間相関は `Σ_k` が担う |
| 閾値 `τ_j` | 順序制約下で `τ_{j,c} ~ N(Φ^{-1}(c/5), 1²)` | 中心値は「潜在反応が標準正規なら各カテゴリが概ね均等」に当たる値。モデル全体の事前予測で均等が保証されるわけではない（§9.4 で確認する） |
| 成分平均 `m_k` | `N_16(0, κ_0^{-1} Σ_k)`, `κ_0 = 0.1` | 原点周辺。§5の中心化は推論後の表示変換であり、この事前に制約を追加しない |
| 成分共分散 `Σ_k` | `IW(ν_0 = 22, Ψ_0 = 0.5 (ν_0 - 17) I)` | 成分内の広がりは全体より小さいという弱い先入観 |
| 成分数 `K` | `K - 1 ~ Poisson(1)`、`γ = 1` | `P(K=1) ≈ 0.37`。事前の同群確率 ≈ 0.736 |

- この組は**初期値**である。事前予測検査（§9.4）を通してから確定し、この表を改訂する。
- `p_K` の平均と `γ` は、どちらも `K` と `T_N` の事後に効く。感度分析（§9.5）の対象とする。

# 4. 推論

## 4.1 使う方法と、NumPyro / HMC を使わない理由

**データ拡張付きの周辺化Gibbs + Jain-Neal split-merge を自前で実装する。** NumPy と SciPy で書く（JAXは、速度が足りないと実測できた時点で検討する）。収束診断には arviz を使う。

| 論点 | 判断 |
|---|---|
| HMCで分割を動かせるか | 離散変数を直接サンプリングしないが、離散変数を周辺化した連続パラメータの推論は可能（[Stan公式資料](https://mc-stan.org/docs/stan-users-guide/latent-discrete.html)） |
| 列挙による周辺化 | 元の `p_K` と `Dirichlet(γ,…,γ)` を保ち、有限範囲のKを扱う方法もある。難しさは可変次元の表現・計算量・打ち切り誤差であり、周辺化が疎な有限混合への変更を必然にするわけではない |
| 自前Gibbsの選択理由と負担 | NIW周辺尤度と分割更新を直接使えるため選ぶ。閾値MH、切断正規、split-mergeの順逆提案確率・受理確率・数値安定性の実装と検証が必要。「HMC版と実装量が大差ない」とは未検証なので主張しない |
| 診断の道具 | arviz（R-hat、bulk/tail ESS、MCSE）はドローの配列があれば使える。HMC固有の診断（発散、木の深さ、E-BFMI）は不要になり、代わりに分割の探索を §4.3 の方法で確認する |

自前Gibbsは必然ではない。実装前の小規模試作で、更新式の導出・split-mergeの詳細釣り合い・小標本の全分割列挙との比較・数値安定化・診断までの作業量と実測時間を記録する。負担が大きければ、同じ事前分布を保つ周辺化HMCやハイブリッド方式を再検討する。

## 4.2 1スイープの手順

| # | 対象 | 更新 |
|---|---|---|
| 1 | `y*_ij`（`j ∈ O_i`） | 切断正規。平均 `λ_j' f_i`、分散1、区間 `(τ_{j,y_ij-1}, τ_{j,y_ij}]`（Albert & Chib 1993） |
| 2 | `τ_j` | 順序制約と `y*` による下限・上限の間で、`N(Φ⁻¹(c/5),1)` を切断して各閾値を直接更新する。これは完全条件付き分布を提案とする受理率1のMH（Gibbs）。一般のランダムウォークMHは不要 |
| 3 | `λ_j` | 共役正規。符号アンカー項目のみ正に切断 |
| 4 | `f_i` | 共役正規。`Λ_{O_i}`、`y*_{O_i}`、所属成分 `(m_{z_i}, Σ_{z_i})` から |
| 5 | `z`（分割） | MFMの周辺化Gibbs。既存ブロック `c` へは `∝ (|c \ i| + γ) · m(f_i | c\i)`、新ブロックへは `∝ γ · V_n(t+1)/V_n(t) · m(f_i)`。`m(·)` は NIW の周辺尤度（閉形式） |
| 6 | `z`（大域移動） | Jain & Neal (2004) の split-merge。制限Gibbsスキャン5回で提案を作り、**MFM用の受理確率**（分割前後の `V_n(t)` と `γ^{(|c|)}` を含む）で判定する |
| 7 | `m_k, Σ_k` | NIW 共役。空でない成分についてのみ |

- 更新順序は上のとおりに固定する。実装時は、各更新が同じ同時分布の条件付き分布であることを式で確認してからコードにする（順序を変えると不変分布が変わりうる）。
- `f_i` は所属 `z_i` を条件づけて引く。**所属を条件づけない `f_i` の条件付き分布は正規ではない**（混合になる）。§7.1 の新規利用者の計算でも同じ点に注意する。
- 5・6 の `m(f_i | ·)` は、その時点の `f` を所与として計算する NIW 周辺尤度である。`f` が 4 で更新される潜在変数であることは Gibbs の正しさを壊さない。

5の `n=N` は除去前の標本サイズ、`t` は `i` を除去し空ブロックを削除した後のブロック数とする。`N=1` では `t=0` から必ず新ブロックに入る。5・6で積分した成分パラメータを7で引き直してから次スイープの4に使う。これは部分周辺化した更新であり、古い成分パラメータを新分割に流用しない。

### 4.2.1 保存時のMFM復元（未観測成分を含む）

保存対象の各分割ドローに、次の条件付きドローを付加する（[MFM原論文](https://jwmi.github.io/publications/MFM.pdf)、§3・§4）。これは学習チェインの分割を変更しない。

1. `t=T_N` とし、`q_s(k)=a_k(N,t)/V_N(t), k≥t` から `K^(s)` を引く。`p(K=k|partition,f,Y)=p(K=k|T_N=t,Y)=q_s(k)`。基底分布がKに依存せず、測定尤度もKに直接依存しない本モデルで成り立つ。
2. 空でない成分を `1..t` に並べ、7の `(m_c,Σ_c)` と人数 `n_c` を保持する。残り `t+1..K^(s)` のパラメータは §3のNIW事前から独立に引く。
3. `w^(s) ~ Dirichlet(n_1+γ,…,n_t+γ,γ,…,γ)` を**全K成分**について引く。空成分の総重みも残し、空でない成分だけで再正規化しない。
4. 代表分割の確定後、空でない成分のIDから代表海域への対応 `g_s` を作る（§6.2）。空成分には `unseen`、対応の付かない既存成分には `alignment_unmatched` を付ける。
5. §5の表示変換は全K成分を含めて計算し、全パラメータ・因子得点に同じ変換を適用する。推論チェインには変換前の状態を残す。

復元前の条件付き期待として、未観測成分への予測確率は `Σ_{k≥t}q_s(k)·γ(k-t)/(N+γk)`。復元した `Σ_{c>t}w_c` の平均がこれとMCSE内で一致することを確認する。`K_post` は `q_s` を全学習ドローで平均して算出し、`draws_K` のヒストグラムとも照合する。

## 4.3 実行と診断

- 4本の独立チェイン。**初期分割を変える**（1群から開始、k-meansで `min(10,N)` 群から開始、無作為割当）。ウォームアップ1,000、保存は各1,000ドローを開始値とし、精度が不足する場合は増やす。
- 収束は識別可能な量で見る：`τ`、`λ`（符号固定後）、固定した数名の `f_i`、`T_N`、対数尤度。**成分ラベルは意味を持たないため、`m_k` や `w_k` に R-hat を計算しない。**
- しきい値：rank-normalized R-hat < 1.01、bulk ESS > 400、tail ESS > 400。
- **表示の判定に使う確率（`P(T_N ≥ 2)`、§9.3）には MCSE を出し、判定境界から MCSE の3倍以上離れていることを確認する。** 境界付近ならドローを増やす。
- 分割の混合は、チェイン間で「代表分割どうしの VI 距離」を比べて見る。**全チェインが同じ局所解に落ちている場合、R-hat では検出できない。** 初期分割を変えることがその対策である。
- `N` が小さいとき `T_N` は定数になりうる（`N=1` なら `T_1=1`）。定数の量に R-hat 判定を適用しない。
- 乱数シード、コミットハッシュ、件数、診断値を `metadata.json` に記録する（ST-CHT-05）。

# 5. 識別性：データで決まる部分と、規約で固定する部分

**この区別を曖昧にしたのが v0.1 の誤りだった。** 対策をしないと、新しい回答が1件もない日でも翌朝には軸が動く。これは体験上の要件でもある。

| 不定性 | 扱い | データで識別されるか |
|---|---|---|
| 位置 `f → f + b`, `τ_{jc} → τ_{jc} + λ_j'b` | 復元した全K成分の平均 `b=Σ_k w_k m_k` を使い、表示用に中心化する | 尤度だけでは識別されない。事前は位置に情報を与える。表示原点は規約 |
| 尺度 `λ → λ/a`, `f → a f` | 全K成分の混合周辺標準偏差 `a_d` を使い、表示用に標準化する | 尤度だけでは識別されない。事前は尺度に情報を与える。表示単位は規約 |
| 因子の回転 | 領域に対応させた確認的な負荷の事前分布（§3）で、特定の向きを**選んでいる**。自由回転は行わない | ほぼされない。**事前情報に依存する部分である**と明記する |
| 因子の符号 | 因子ごとに1項目（符号アンカー）の主負荷を正に切断する | されない。規約で固定する |
| 成分ラベル | 固定しない。出力はすべてラベル不変な量で定義する（§6） | — |

- 中心化・標準化は推論後の各ドローの派生量とし、チェインの事前分布を変更しない。`A=diag(a)` として `f̃=A⁻¹(f-b)`、`m̃_k=A⁻¹(m_k-b)`、`Σ̃_k=A⁻¹Σ_kA⁻¹`、`λ̃_j=Aλ_j`、`τ̃_jc=τ_jc-λ_j'b`。変換後も回答確率は同じ。§7には変換後の配列と `b,a` を保存する。以降の表示・新規予測では変換後の記号を省略して `f,λ,τ,m,Σ` と書く。
- 「事前分布で回転を固定した」とは書かない。正しくは「尤度では区別しにくい表現のうち、領域設計に沿うものを事前分布で選んでいる」である。交差負荷を自由にしている以上、この選択はデータでは検証できない。検証できるのは**適合**であり、交差負荷の事後が大きい項目や主負荷が0に近い項目をレポートに出して、項目設計を見直す材料にする（§10、§11）。
- 符号アンカー以外の主負荷は切断しないため、**設計と逆向きの負荷は検出できる**。符号アンカー項目については検出できない。アンカーは、内容が明確でパイロットで挙動を確認した項目から選ぶ。

## 5.1 2次元への射影
表示用の射影 `x=P f+c` は、回答を観測する前から固定する。列順はD01〜D16、`P[1,D01]=1`、`P[2,D04]=1`、その他は0、`c=(0,0)` とする。横軸は「対人接近性」、縦軸は「探索・新奇性」という質問領域の意味に対応する。これは16次元のうち2領域を表示する規約で、人格全体を代表する軸を発見したという主張ではない。海域の推定は16次元で行うので、異なる海域が2次元では重なりうる。

- `PP'=I_2` であり、1人から同じ射影が定義できる。中心化PCAの最大ランクは `N-1` なので、初回PCAは採用しない。
- **固定Pだけで経年比較は保証されない。** §5の中心・尺度は各版・各ドローで変わり、測定モデルや項目版の更新でも位置は動く。通常の海図はその版の集団に対する相対位置である。
- 経年比較用は参照する成果物（測定モデル、全ドロー、中心・尺度、P、c、項目版）を固定して、各時点の回答を §7.1で再計算する。同じ尺度に戻せない項目改訂や測定不変性が未確認の比較は連続した変化と解釈しない。
- P・軸の意味の変更は **CHART UPDATE** とし、`projection_version` と参照成果物IDを保存する。Procrustes整列は補助表示に限り、異なる測定モデルの同等性を保証するものとして使わない。

## 5.2 海域IDの継承
代表分割（§6.1）の各クラスタを、前の版のクラスタと、共有する観測者の重なり（Jaccard 係数）で対応づけ、Hungarian法で決める。対応が付かないクラスタには新しい `lineage_id` を発行し、`split` / `merge` / `new` として記録する（[concept.md](concept.md) §57.2）。

# 6. 出力の定義

## 6.1 代表分割
海図を一枚に確定させるため、事後の分割から代表を1つ選ぶ。規則は固定する：**Variation of Information 損失の事後期待値を最小にする分割**（Wade & Ghahramani 2018）。

    Ĉ = argmin_partition E_posterior[ VI(partition, z) ],    T̂ = |Ĉ|

- 探索範囲は、保存順に等間隔で選んだ最大64個の分割候補とする。全保存ドローに対する期待VIを評価する。したがって得られるのは**近似最適解**であり、候補数はメモリ使用を制限する計算設定として記録する。
- 期待値は保存したドローに対する平均で計算する。`N×N` の共クラスタ行列は作らない（§8）。
- credible ball（同論文）は、**信用水準 0.95**、距離は VI、半径は `log N` で正規化して報告する。`N=1` は分割が一通りのため、0除算を避ける定義上の規約として半径0とする。全人数で報告し、「標本内の分割の不確実性であり、母集団構造の確信ではない」と説明する。人数しきい値による表示分岐は設けない。
- 「統合の誤りと分割の誤り、どちらが困るか」は損失関数の選択として固定する。VI は Binder 損失より過分割に厳しい。人数によって規則を変えない。

## 6.2 所属確率（ラベル不変な定義）
v0.1 の「代表クラスタ構成員との平均共クラスタ確率」は、排他的な事象の確率ではなく、所属確率ではなかった。次の定義に置き換える。

1. 各ドロー `s` について、そのドローの分割のクラスタを、代表分割のクラスタへ Hungarian法で対応づける（重なり最大化）。対応が付かないクラスタは `unmatched` とする。
2. 観測者 `i` のドロー `s` での所属先を `g_s(z_i^{(s)}) ∈ {1..T̂, unmatched}` とする。
3. `p_ik = (1/S) Σ_s 1[g_s(z_i^{(s)}) = k]`。

- `Σ_k p_ik + p_i,unmatched = 1`。`unmatched=alignment_unmatched+unseen` の内訳を保存・返却する。前者は統合・分裂などで代表海域への表示上の対応が付かない事象、後者は新規利用者が学習標本で空だった成分に入る事象である。「既知のどの海域にも収まらない」と一括して解釈しない。学習標本の本人では `unseen=0`。
- APIには上位3件と `unmatched` を返す。**上位3件だけで再正規化しない。**
- `near_boundary` は1位と2位の差が 0.2 未満のときに真とする。これは表示上の規則であって統計的な境界の検定ではない。画面でもそう書く。
- 新規利用者も同じ `g_s` で表示先を定めるが、確率は §7.1のcut分布で計算する。対応表はそのドローの全学習分割と代表分割の重なりで作り、重なり0の割当は未対応とする。同点は保存された成分ID・代表海域IDの昇順で決める。自己一致（`P(z_i=z_i)=1`）を所属確率として使わない。

## 6.3 個人の現在地
`f_i` の事後から `x_i = P f_i + c` の事後を作る。

- 既定は**全員に同じ2次元グリッド信用領域**を使う。§8の2次元ドローからGaussian KDEでセル確率を推定し、密度（確率/面積）の高い順に累積確率が0.95以上になるまでセルを採る。同密度の境界セルはすべて含め、実際の含有確率も返す。多峰判定で方式を切り替えない。これは平滑化したグリッド上のHPD近似であり、連続事後の厳密なHPDとは区別する。帯域行列は `H=S_eff^(-1/3) Cov(x)`（2次元Scott則、`S_eff` は両座標のESSの小さい方）を開始値とし、0.5倍・2倍の感度を保存する。特異共分散の場合は支持部分空間上の信用集合を返し、人工的に2次元へ広げない。
- 平均・共分散だけでは形状も95%確率質量も定まらない。楕円を補助表示する場合は、各ドローのマハラノビス距離二乗の経験95%点を半径二乗とし、χ²分位点を無条件に使わない。特異共分散では楕円を返さない。経験的に校正した楕円も、歪み・多峰による低密度部分を含みうるのでHPDとは呼ばない。
- グリッドは全ドローを収め、KDEの範囲外質量が0.001以下になるまで拡張した範囲で64×64から始め、128×128、256×256へ細分化する。領域面積の相対変化5%以内、確率質量の変化0.01以内を確認し、未達なら解像度・ドローを追加する。交互のドローではなくチェインを分けて構築用・評価用とし、評価側の含有率とMCSEを報告する。評価含有率と構築時質量との差が `max(0.01,3×MCSE)` を超える場合も追加し、平滑化誤差とMC誤差を区別する。cutでは外側の学習チェインごと分離する。
- `latent_se` は事後標準偏差。`confidence=1/(1+tr(Cov(f))/16)`（縮小検証モデルでは16を因子数に置換）とする。事後分散の平均に単調減少する表示用の指標であり、正答確率ではない。

## 6.4 群数：3つを区別する

| 量 | 定義 | 報告 |
|---|---|---|
| `T_N` | この標本で埋まった成分の数 | **`P(T_N = t | Y)` を保存・公開する。表示の判定にもこれを使う** |
| `K` | 母集団モデルの成分数 | 参考として `P(K = k | Y)` を保存する。`T_N ≤ K` であり、`K` はデータからは弱くしか決まらない |
| `T̂` | 代表分割の海域数（§6.1） | 画面に現れる海域の数。`P(T_N)` の最頻値と一致しないことがある |

- 点推定は出さない。`T̂` は「表示のための決定」であって推定値ではないと、画面でも区別する。
- **成分数は「実在する人格タイプの数」ではない。** ガウス成分は分布の歪みや裾を表すために増えることがある（Bauer & Curran 2003）。複数成分でも密度が単峰のことはある。§9.2 の歪んだデータでの検証と §9.4 の事後予測で、この振る舞いを確認する。
- 説明文では「いくつの群に分かれるか」ではなく「いくつの成分で分布をうまく表せるか」と書く。

## 6.5 公開する海図
研究参加者の `x_i`（事後平均）の2次元ヒストグラム。**人数が `k` 未満のセルは出さない**（FR-CHT-04、既存実装 `density_map`）。回答者が数人のとき、この規則により公開の密度図は空になる。仕様どおりの動作であり、異常ではない。

# 7. 成果物の形式

点推定を1組だけ置くと、新規利用者の位置が「パラメータ既知の条件付き事後」になり、モデル推定自体の不確実性を落とす。黎明期にはこの差が大きい。そこで**間引いた事後ドローを保存する**。

| ファイル | 内容 |
|---|---|
| `model.npz` | `draws_tau` (S×J×4)、`draws_Lambda` (S×J×16)、`draws_w` (S×C)、`draws_m` (S×C×16)、`draws_Sigma` (S×C×16×16)、`draws_valid`・`draws_occupied` (各S×Cのbool)、`draws_K`・`draws_T` (各S)、`draws_component_to_region` (S×C)、`draws_core_z` (S×\|core\|、**ドロー内の元の成分ID**)、`center_b` (S×16)、`scale_a` (S×16)、`P` (2×16)、`c` (2)、`T_post`、`K_post`とその支持点 |
| `metadata.json` | `version`、`item_set_version`、`question_ids`、`domain_order`、`projection_version`、`reference_artifact_id`、`inference_mode=cut`、`regions`（代表海域 → `lineage_id`）、`core_user_index`、`S`、`C`、配列の型と欠損・未対応コード、チェインとドローのID、`diagnostics`（R-hat、ESS、MCSE、credible ball、級数誤差・上限拡大検証、信用領域の精度）、`seed`、`commit`、`n_observers` |

- `S=200` は開始値であり、§7.1のMCSE検証で増やす。`C=max_s K^(s)` は保存時のパディング幅であり、モデルの上限ではない。成分IDは各ドロー内の配列インデックス。`valid` は実在する全K成分、`occupied` はうち学習時に空でない成分を示す。パディングの重みは0、`Σ_{valid}w=1`。

- float64で主要配列の容量は `8S[20J+273C+32]` bytes程度（付随配列を除く）。例として `J=238,C=15,S=200` なら約14.2 MBだが、`C≤15` は保証しない。Kを容量のために切らず、実際の容量を記録する。

- `draws_core_z` は核となる観測者の所属確認用であり、新規利用者の対応づけには全成分の対応表を使う。代表分割と学習時の分割ドローは非公開の研究用ファイルに別途残し、対応表の生成を監査できるようにする。
- `center_b`・`scale_a` があることで、標準化前の尺度に戻せる（§5）。
- 配列を読むのは `pipeline` と日次バッチだけである。APIは `metadata.json` しか読まない（design D-5、NFR-PRF-02）。

## 7.1 学習に参加していない観測者の位置（日次バッチ）

学習参加者は同時推定の事後、それ以外（新規、非同意）は**学習モデルへのフィードバックを止めるcut型推論**を使う。`θ` は §4.2.1で復元したK、全成分、重み、測定パラメータを含む。このモジュール境界を固定し、非同意者の回答で共通モデルや学習ドローの重みを更新しない（[Plummerのcut解説](https://statmath.wu.ac.at/research/talks/resources/Plummer_WU_2015.pdf)）。

    p_cut(f_new,z_new | y_new; Y)
      = ∫ p(f_new,z_new | y_new,θ) p(θ|Y) dθ
      ≈ (1/S) Σ_s p(f_new,z_new | y_new,θ^(s))

1. 各固定ドローの全valid成分について `p(f_new|θ)=Σ_c w_c N(f_new|m_c,Σ_c)` を使う。空成分も除かない。
2. `y*|f,y,θ` を切断正規、`z|f,θ ∝ w_c N(f|m_c,Σ_c)`、`f|z,y*,θ` を共役正規として内側Gibbsを回す。**各sの内側事後を正規化してから等重みで混ぜる。** 初期成分を変えた複数チェインで位置と所属の混合を確認する。
3. 各sで `g_s(z_new)` に対応させ、代表海域・`alignment_unmatched`・`unseen` の確率を集計する。本人の `x=P f+c` もドローとして保存する。新規利用者間ではパラメータや空成分を更新・共有学習しない。
4. 内側ESSとMCSE、外側Sを増やした再計算の差を分けて測る。代表的な回答・欠測条件で、所属確率と `unseen` の差 `≤0.01`、位置平均の各座標の差 `≤0.02`、各MCSEが許容差の3分の1以下を要求する。信用領域は §6.3も満たすまでS・内側スイープ・保存数を増やす。200ドローを精度保証とはしない。

**通常の完全ベイズ事後とは異なる。** 完全ベイズでは

    p(f_new | y_new,Y) = ∫ p(f_new | y_new,θ) p(θ | y_new,Y) dθ
    p(θ | y_new,Y) ∝ p(y_new | θ) p(θ | Y)
    α_s = p(y_new | θ^(s)) / Σ_r p(y_new | θ^(r))

となり、学習ドローを使うなら `Σ_s α_s p(f_new|y_new,θ^(s))` とする。`p(y_new|θ)` は成分と本人の因子得点を積分した周辺尤度であり、点推定で代用しない。完全ベイズを研究用に計算する場合は重要度重みのESSを確認し、不足時は再推定する。サービスはcut型を採り、完全ベイズ事後と表記しない。cutの被覆率は通常のベイズ校正から自動的に保証されず、§9で別に検証する。

必要なスイープ数・保存数・所要時間は測定する。「1人あたりミリ秒台」とは仮定しない。

# 8. 計算量と保存量

**v0.1 の見積もりは方式と整合していなかったので作り直す。** 以下は設計上の目安であり、実測値で置き換える。

| 項目 | 見積もり |
|---|---|
| 1スイープの主な負荷 | `y*` の切断正規サンプリング。総回答数（`N × 約98`）に比例する。Gibbs では `y*` を保持するため、この評価は方式と整合する |
| メモリ（`N=2万`） | `y*` と `f` の現在値で約 16 MB と約 2.6 MB。**全ドローの `f` は保持しない**（2万人×16×4,000ドローで約 10 GB になる） |
| 個人位置の保存 | 16次元は全員の走る平均・共分散と診断対象者のドロー。**2次元は全員について**変換後のドローを分割ファイルに保存する。`S_x=1,000` を開始値として §6.3の精度に応じて増やす。2万人×1,000×2×float32なら約160 MB（メモリ常駐不要）。新規利用者は外側ドローが等重みとなるよう保存する |
| 分割の要約 | `N×N` の共クラスタ行列は作らない（2万人で約 3.2 GB）。期待VIは、候補分割と各ドローの分割の間で直接計算する（1ドローあたり `O(N + t²)`） |
| 成果物 | 共通モデルは §7の式で算出。個人位置ファイルと研究用分割ドローは別。分割4,000本を2万人分int32で保存すると約320 MB。対応表・VI計算にはこれを順次読み出す |

規模ごとの方針：

| N | 方針 |
|---|---|
| 〜2万 | 全数で推定する。夜間に収まるかを実測し、この表を更新する |
| 2万〜 | **推定は部分標本、位置は全数**（§7.1）。ただし得られるのは「部分標本に条件づけた事後」であり、全回答に条件づけた事後ではない。学習に使わなかった回答の情報は、あとから位置を計算しても戻らない。小さな海域が抽出から漏れうる。抽出のシードと、層化の有無・漏れの確認を記録する |
| 100万〜 | 生成モデル・推定対象・意思決定規則は変えず、計算の近似（SVI、ミニバッチ、部分標本）を替える。**近似を替えるときは §9 の検証を再実行し、前の方式との差を報告する。** 「同じ推論」ではなく「同じモデルと同じ規則」が保たれる、という言い方に統一する |

# 9. 検証

## 9.1 SBC（simulation-based calibration）
事前分布からパラメータと回答を生成し、推論を回して、真値の順位統計が一様分布になるかを確認する（Talts et al. 2018）。項目数と因子数を縮めたモデル（例：`J=20`、因子4、`N=100`）で行う。推論実装の誤りを検出する手立てである。

## 9.2 合成データからの回復（反復して測る）
20反復は動作確認に限る。本評価は条件ごとに**独立な生成1,000反復**を固定して行う。比率はWilson 95%区間、連続指標は反復単位のbootstrap 95%区間を報告する。真の被覆率0.95なら標準誤差は20反復で約0.049、1,000反復で約0.0069。MCMCのMCSEと反復実験の標準誤差を区別する。

| 条件 | 測る量 |
|---|---|
| 真の `K=1`、N=300 | `P(T_N=1)` と、§9.3の**複数海域表示規則全体**による偽陽性率 |
| 真の `K=3`（離れた平均）、N=900 | 実現した真の占有数 `T_N^true` に対する群数誤差・群数信用集合の被覆、複数群の検出率、真の分割と代表分割の正規化VI。K回復は別に評価 |
| 真の `K=3`（重なった平均）、N=200 | 検出率・群数誤差、所属の校正とBrier score、credible ballの真の分割被覆、誤った分割への集中（正規化VI>0.25なのにball半径≤0.05となる割合）。複数群を検出しただけでは誤確信としない |
| `N=1` | `T_1=1`、固定Pの定義、有限な位置計算を確認する。反復全体で、回答前後の事後分散のトレース・領域面積・被覆を比較し、各データで狭まるとは要求しない |
| 個人位置 | 学習事後と新規利用者cutを分け、98・49・25項目の入れ子欠測で領域面積の平均差・分散トレースの平均差・95%領域被覆を測る。回答減少時の個々の領域の単調拡大は要求しない |

- 生成条件（平均間のマハラノビス距離、混合比、共分散、測定パラメータ、欠測機構）は予備実験で数値を定め、本評価の前にシードとともに設定ファイルへ固定する。「離れた」「重なった」だけを再現条件にしない。所属校正では真の成分との一対一対応を求め、未対応成分も別カテゴリとして校正曲線とBrier scoreに含める。表示上の対応誤差は別に記録する。
- 学習標本の真の位置は各ドローと同じ表示変換の定義に従って評価する。生成した全K成分の真の中心・尺度で定めた `x_true` を用い、未標準化の真値と標準化後の領域を比較しない。
- **本評価の受入基準**：正しく指定した条件の95%個人領域・分割ballの被覆率はWilson区間全体が `[0.92,0.98]` 内、真に1群の複数海域表示率は片側95%上限 `≤0.05`、離れた複数群の検出率は片側95%下限 `≥0.90`。分割ballの離散性による過剰被覆は、実際の事後含有質量も報告して別途判定し、狭い意味の95%校正合格とはしない。cutで基準を満たさない場合は校正を保証せず、表示規則・モデルを改訂して新しい本評価を行う。
- 母集団パラメータも1人の回答で更新される。本人の位置・母集団のどちらについても、事後が事前に一致する、または各データで必ず狭くなるとは要求しない。
- 誤指定データでも評価する：歪んだ因子分布、裾の重い分布、局所依存（似た言い回しの項目対に相関を仕込む）、不注意回答の混入。**ガウス成分が歪みを群として拾ってしまう頻度**をここで測る（§6.4）。

## 9.3 表示の判定と、そのモンテカルロ誤差
判定の式（requirements FR-UNC-03、FR-UNC-05 が参照する。**暫定値であり §9.2・§9.4 の結果を見て確定する**）：

| 表示 | 条件 |
|---|---|
| 海域と所属確率を出す | `P(T_N ≥ 2 | Y) > 0.5` **かつ** 代表分割が `T̂ ≥ 2` |
| 「まだ群として分かれていない」と出す | 上を満たさないとき。**両者が食い違う場合もこちら**とし、食い違い自体を運営のレポートに出す |
| 「暫定海図」と付ける | credible ball 半径（正規化VI）> 0.25、または位置の事後標準偏差の中央値 > 0.5。人数による分岐は設けない |

`P(T_N ≥ 2)` の MCSE が判定境界に対して十分小さいこと（§4.3）を、成果物を作る条件に含める。

「暫定」の有無は研究上の安定化（§0.3）の結論ではない。母集団構造が未検証である旨は人数にかかわらず表示する。表示規則は予備実験で調整できるが、本評価中は固定し、不合格を見て同じ評価データに合わせ直さない。

## 9.4 事前予測検査と事後予測検査
- **事前予測**：事前分布から回答を生成し、5件法として現実的か（全カテゴリが出現し、端に極端に偏らないか）を見る。偏るなら §3 を直す。
- **事後予測**：端カテゴリの出現率、項目ごとの分布、項目ペアの相関（同一領域内、逆転項目対）、`data_quality_score` で層別した分布を、観測データと比べる。**天井・床効果はここで評価する**（§2.1）。局所独立性の確認もここで行う（§10）。
- 比較尺度（`kind='comparison'`）は推定から除くが、**外的妥当性の検討には使う**。因子得点と比較尺度の相関を推定ごとにレポートへ出す（ST-EXT-02 の範囲。利用者の画面には出さない）。

## 9.5 感度分析
`p_K` の平均、`γ`、主負荷の事前平均と分散、`Ψ_0`、`κ_0` を変えて、`P(T_N)`・代表分割・表示判定がどれだけ動くかを記録する。動くなら、その旨を運営のレポートと公開文書に書く。

# 11. 既知の限界

- **軸は発見ではなく仮説である**（§5）。16領域の枠組みそのものをデータから見直す作業は、このモデルの外で行う。交差負荷の事後が大きい項目、主負荷が0に近い項目をレポートに出し、項目改訂の材料とする。
- 回転は事前情報に依存する。尤度で区別しにくい別の回転が同等の適合を示す可能性は残る。
- 交差負荷の正規事前は疎性を強く入れない。項目が増えたら horseshoe などに替える（LATER）。
- 部分標本での推定は、全データに条件づけた事後ではない（§8）。
- 成分数は人格タイプの数ではない（§6.4）。
- 符号アンカー項目の負荷の向きは、規約として固定するためデータでは検証できない（§5）。

# 12.1 研究専用の年齢・性別共変量（2026-09-23追加）

登録時に出生**年・月のみ**と「現在の性別について、最も近いものを選んでください。」への回答を必須とする。選択肢は「男性」「女性」「男性・女性のどちらにも当てはまらない」「回答したくない」。日付は取得・補完しない。性別は本人の回答であり、出生時の性別・外見・回答内容から推定しない。18歳以上の確認は従来のチェックボックスによる自己申告であり、この研究情報を利用資格判定には流用しない。

**利用目的は同意者の回答傾向を調べる非公開の研究用回帰分析に限定する。** 海図のMFM、個人位置、設問選択、認証、広告、個人評価には入力しない。新しい研究説明書（版2）への最新の同意が有効な人だけを抽出する。撤回者・削除者・既存アカウントの未入力値を補完しない。専用の非公開DBテーブルで保存し、API・日次バッチのロールには読み取り権限を与えない。

解析カットオフを日本時間に変換し、その月の1日の前日を `age_reference_date` とする。出生年月 `(Yb,Mb)` に対する年齢は `Yr-Yb-I(Mr<Mb)`。例：2026年9月の解析では2026-08-31基準、2000年8月生まれは26歳、2000年9月生まれは25歳。これは月末基準の満年齢であり、解析当日の正確な年齢ではない。基準日より後の出生年月は不正入力として拒否し、年齢そのものは永続プロフィールへ保存しない。タイムゾーンのないカットオフは拒否する。

**探索的なcut型補助回帰**：上流の測定・混合モデルにはフィードバックせず、保存対象の各標準化因子ドロー `F^(s)` に対して、領域 `d` ごとに `F_id ~ Normal(X_i β_d, σ_d²)` を計算する。`X=(1,(age-50)/10,I(gender=male),I(gender=neither))`、女性を参照カテゴリとする（価値判断・順序ではない）。`prefer_not_to_say` と未入力は主解析では完全ケースから除外し、除外数を非公開レポートに記す。性別の欠測を別の性別に分類しない。欠測による選択バイアスを限界として明記し、因果効果・母集団の一般則とは解釈しない。

事前は独立な領域ごとに `σ_d² ~ InverseGamma(shape=2, scale=1)`、`β_d | σ_d² ~ Normal(0, σ_d² V0)`、`V0=diag(100,1,1,1)`。`A=V0^-1+X'X`、`b=A^-1 X'F_d`、`a=2+n/2`、`r=1+(||F_d-Xb||²+b'V0^-1 b)/2` とし、各上流ドローから `σ²~IG(a,r)`、`β~N(b,σ²A^-1)` を1回抽出して等重みで混合する。これは `∫p(β,σ²|F,X)p(F|Y)dF` というcut分布で、完全ベイズの共同事後や確定因子得点の回帰ではない。標準化尺度と上流推定の不確実性を引き継ぐ。独立した乱数ストリームを用い、共変量の有無でMFMのドローを変えない。全員分の16次元ドローは追加保存せず、サンプリング中に回帰係数を集計する。

完全ケースが0人なら係数は出さず `no_complete_cases` を返す。少人数・単一性別・年齢が一定でも同じproper priorを使い、設計行列のランク不足はレポートに明記する。係数の平均・等裾95%区間・R-hat/ESSを非公開領域に保存し、公開モデル成果物・公開APIには載せない。収束未達は未達と記録し、因子モデルの収束と区別する。少数区分は公表せず、公表前には別途集計・開示審査を必要とする。

**テスト契約**：年跨ぎ・閏年・出生月前後・JST月境界、年月/性別の検証、不同意/撤回/削除/旧版同意の除外、出生年月を公開成果物へ保存しないこと、未知性別を推測しないこと、共役事後の平均/分散との一致、全欠測・ランク不足、補助回帰の有無でMFMドローが同一であることを検証する。登録では4必須チェックに加え出生年月と性別選択を要求し、「回答したくない」で登録可能とする。

登録動線は事前情報・同意画面と認証手段選択を分離する。Google OAuthを主手段、メール・パスワードを代替とする。出生年月・性別はAuthメタデータに載せず、同一タブの24時間有効のドラフトとして認証往復を越える。認証後、専用APIが本人の属性と同意を原子的に保存してドラフトを消去する。未完了アカウントはサーバー側でも測深を拒否する。ドラフトがない場合や同意版が更新された場合は、登録完了画面で再確認する。
