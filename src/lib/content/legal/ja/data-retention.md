# データの保存と削除

版：1　施行日：【要記入】

## 基本方針

**保存する目的がなくなった個人データは持ち続けません。**「念のため」の無期限保存は行いません。以下の保存期間と削除の約束は、当方が自ら定めたものです。

## 保存期間

| データ                                                                   | 保存する目的                                                               | 保存期間                                                                                                         |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| メールアドレス・認証情報                                                 | 本サービスの提供                                                           | アカウントが存在する間                                                                                           |
| 回答データ・回答時間・推定結果・航跡・回答品質の指標                     | 本サービスの提供、研究（参加者のみ）                                       | アカウントが存在する間。研究に参加している場合は、加えて研究終了後【要記入】年まで（下記「研究が終了したとき」） |
| 本人識別情報と研究データの対応表                                         | 結果の表示、撤回・削除への対応                                             | アカウントが存在する間（研究終了時の扱いは下記）                                                                 |
| 同意・撤回の記録                                                         | 同意・撤回の内容と時期の確認および証明                                     | アカウント削除後も【要記入】年（仮名IDと記録のみ）                                                               |
| 削除済みを示す記録（仮名IDと削除日時のみ）                               | 削除した方のデータが、バックアップ等から復元された場合に確実に除外するため | 削除から【要記入：バックアップの最長保持期間と同じ期間】                                                         |
| 当方のAPIの通信記録                                                      | 障害対応、不正利用の防止                                                   | 【要記入】日                                                                                                     |
| 外部事業者が保持するアクセス記録（認証、配信、通信の保護）               | 各サービスの提供                                                           | 各事業者の設定による（【要記入：事業者ごとの期間】）                                                             |
| バックアップ                                                             | 障害からの復旧                                                             | 最長【要記入】日                                                                                                 |
| 問い合わせ・請求の記録                                                   | 対応の経過の確認                                                           | 対応完了から【要記入】年                                                                                         |
| 特定の個人との対応関係を排除した統計情報（公開される人格海図、統計資料） | 研究成果の公表                                                             | 期限を定めない                                                                                                   |

## 研究への参加をやめたとき

1. データは削除せず、あなたへの結果の表示のために保存します。
2. 以後、研究のための統計解析に用いません。
3. 次の日次更新（日本時間の午前1時）から、人格海図の密度・集計に含めません。座標軸と海域の推定し直しは、次回のモデルの改訂で行います（公開済みの人格海図は遡って作り直しません）。

## アカウントを削除したとき

削除の操作をした時点で、本サービスの本番データベースから次の情報を消去し、以後いかなる目的にも利用しません。

- メールアドレス・認証情報
- 回答データ・回答時間・推定結果・航跡・回答品質の指標
- 本人識別情報と研究データの対応表

次の情報は、上記の保存期間のあいだ残ります。

| 残る情報                                                   | 理由                                 | 削除の時期                                                                                                                                                   |
| ---------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| バックアップに含まれるデータ                               | バックアップは個別に消去できないため | バックアップの保持期間の経過時に自動的に消去。**この間に障害等でバックアップから復元した場合は、削除済みを示す記録に基づいて直ちに再び消去し、利用しません** |
| 同意・撤回の記録（仮名IDのみ、メールアドレス等は含まない） | 同意・撤回の証明                     | 上記の保存期間の満了時                                                                                                                                       |
| 削除済みを示す記録（仮名IDのみ）                           | 復元時に確実に除外するため           | 上記の保存期間の満了時                                                                                                                                       |
| 通信記録・外部事業者のアクセス記録                         | 障害対応、不正利用の防止             | 上記の保存期間の満了時                                                                                                                                       |

研究のための解析作業で作成したデータの複製は、作業の完了後に削除します。やむを得ず作業用の複製を残す場合も、次の解析の前に、削除済みを示す記録と照合してあなたのデータを除外します。

すでに作成・公開された人格海図は、特定の個人との対応関係を排除した統計情報であるため遡って作り直しません。次の日次更新から人格海図の密度・集計に含めず、次回のモデルの改訂では、あなたのデータを除いた観測データのみから推定し直します。

## 研究が終了したとき

1. 研究の終了と、その後の手順・時期は、事前に本サービス上でお知らせします。
2. 研究データを研究終了後も保存する場合、その期間は研究終了後【要記入】年とし、満了時に削除します。
3. 本人識別情報と研究データの対応表を削除する場合は、その時期を事前にお知らせします。対応表を削除した後は、あなたのデータを特定できないため、撤回や削除の請求に応じることができなくなります。なお、対応表を削除しただけで、残ったデータが当然に個人情報に当たらなくなるわけではないため、その後も法令に従って取り扱います。

## ブラウザに保存される情報

ログイン状態はログアウトまで、送信前の回答はサーバへの送信が完了するまで、あなたの端末に保存されます。ログアウト時とアカウント削除時には、その端末に保存された送信前の回答も削除します。他の端末の情報は、その端末でログアウトするか、ブラウザの保存データを削除してください。
