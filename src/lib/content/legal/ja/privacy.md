## 3. 利用目的

1. 本サービスの提供（認証、測深、結果の表示、航跡の表示）
2. 研究への参加に同意いただいた場合の、研究目的での統計解析および人格海図の作成（「[研究説明書・研究参加への同意](/legal/research)」）
3. 回答品質の確認および不正利用の防止（自動回答、統計の意図的な操作の検知）
4. 本サービスの保守、障害対応、セキュリティの確保
5. 同意・撤回・削除の対応状況の確認および証明
6. 問い合わせ・請求への対応
7. 重要なお知らせ（規約改定等）の送付

これらの目的の範囲を超えて利用する場合は、あらかじめ本人の同意をいただきます。

## 4. 研究データと本人識別情報の分離

1. 研究のための統計解析では、メールアドレス等の本人を識別する情報を含まず、ランダムな識別子、回答、回答日時、回答時間、推定結果、回答品質の指標からなるデータを用います。本人を識別する情報と研究データの対応表へのアクセスは、限られた者に制限します。
2. これは当方による**分離管理**であり、個人情報保護法に定める「仮名加工情報」の制度を用いるものではありません。本サービスでは結果の表示や削除の請求への対応のために対応表を保持しているため、**研究データも通常の個人データとして取り扱います**。
3. 研究への参加に同意していない方、および参加をやめた方のデータは、研究のための統計解析に用いません。

## 5. 第三者提供

1. 当方は、法令に基づく場合を除き、本人の同意なく個人データを第三者に提供しません。
2. 研究成果の公表（公開される人格海図、論文、学会発表、統計資料）では、**特定の個人との対応関係を排除した統計情報のみ**を用います。人数の少ない区分は集約するか公表しません。他の利用者の個別の回答や位置を公開することはありません。

## 7. 安全管理措置

当方は、個人データの漏えい・滅失・毀損を防ぐため、次の措置を講じます。

| 区分           | 措置                                                                                                                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 組織的・人的   | 個人情報の取扱いに関する責任者を定め、取り扱う者の範囲と役割を限定し、取扱いの規程を定めて教育を行います。漏えい等の発生時の報告・対応の手順を定めます                                                                 |
| 技術的         | 通信の暗号化（HTTPS）、データベースにおける行単位のアクセス制御、研究データと本人識別情報の分離、管理用アカウントの多要素認証、当方が開発するAPIのログにパスワード・認証情報・回答内容・メールアドレスを記録しないこと |
| 委託先の監督   | 外部事業者の選定時と定期的に、セキュリティ体制と契約内容を確認します                                                                                                                                                   |
| 外的環境の把握 | 外国の事業者を利用するにあたり、第6項の国の個人情報の保護に関する制度を把握したうえで措置を講じます                                                                                                                    |

## 9. 開示等の請求

### 9.1 請求できる内容

本人は、当方が保有する自己の保有個人データについて、次の請求ができます（個人情報保護法第32条〜第35条）。

- 利用目的の通知
- 開示（第三者提供の記録の開示を含む）
- 内容が事実でない場合の訂正・追加・削除
- 法令の要件に該当する場合の利用停止・消去・第三者提供の停止

### 9.2 請求によらずにできること

次の操作は、請求の手続によらず、設定画面からいつでも本人が行えます。

- **研究への参加をやめること**（アカウントは残り、以後あなたのデータは研究のための統計解析に用いられません）
- **アカウントの削除**（削除される情報と例外は「[データの保存と削除](/legal/data-retention)」のとおりです）

### 9.3 請求の方法

1. 第11項の窓口に、登録したメールアドレスから、請求の内容を記載してお送りください。
2. **本人確認**：登録したメールアドレスからの送信であること、および当方からの確認メールへの返信により確認します。住所や本人確認書類の提出は原則として求めません。本人確認ができない場合には、追加の確認をお願いすることがあります。
3. **代理人による請求**：法定代理人または本人が委任した代理人は、代理権を確認できる書類（委任状等）と、代理人自身の本人確認書類を添えて請求できます。【要記入：提出方法】
4. **開示の方法**：本人が指定する方法（電磁的記録の提供または書面の交付）により開示します。電磁的記録の場合は、機械で読める形式（CSV等）のファイルで提供します。指定の方法による開示が困難な場合は、書面で開示します。
5. **手数料**：【要記入：無料とする場合はその旨。有料とする場合は、利用目的の通知・開示の請求について、その金額と支払方法】

### 9.4 対応

1. 当方は、請求を受けたときは、法令に従い遅滞なく対応します。
2. 請求の全部または一部に応じない場合（法令により開示しないことができる場合、請求が法令の要件を満たさない場合等）は、その旨を遅滞なく通知し、あわせてその理由を説明するよう努めます。

## 10. ブラウザに保存する情報

本サービスは、ブラウザの保存領域（localStorage）に次の情報を保存します。広告・追跡目的のCookieは利用していません。

| 情報                         | 保存される期間                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| ログイン状態（認証トークン） | ログアウトするまで                                                                                 |
| 送信前の回答                 | 当方のサーバへの送信が完了するまで。ログアウト時およびアカウント削除時にも、その端末から削除します |

これらはあなたの端末に保存される情報であり、当方のサーバ上の情報とは別のものです。他の端末に残っている情報は、その端末でログアウトするか、ブラウザの保存データを削除することで消去されます。
